### 📦 Installation
1. Download **Ultimate ASI Loader** ( `dinput8.dll` or `dxgi.dll`): https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases
2. Place `UC-3D-6DOF.asi` and `3D-6DOF config.ini` into your game directory right next to `game.exe`.
